# Privacy Policy - Space Command

**Last Updated:** June 2026

## 1. Overview

Space Command ("the App") is committed to protecting your privacy. This Privacy Policy explains how we handle data when you use our application.

**Key Point**: We do NOT collect, store, or transmit any personal information about you.

## 2. Data We Do NOT Collect

❌ No user accounts  
❌ No email addresses  
❌ No location data  
❌ No device identifiers  
❌ No analytics or tracking  
❌ No advertising  
❌ No third-party data sharing  

## 3. Data We Store (Locally Only)

All data stored on YOUR device, never sent to servers:

- **Notification preferences** - Which launches you want alerts for
- **Language preference** - Your chosen language (FR/EN)
- **App cache** - Recent API responses (5-minute cache)

This data stays on your device and is NOT transmitted anywhere.

## 4. APIs We Use

### Launch Library 2 API
**Provider**: The Space Devs  
**Purpose**: Fetch SpaceX launch data  
**Data**: Public launch information (names, dates, rockets)  
**URL**: https://ll.thespacedevs.com/2.3.0  
**Privacy**: They collect no personal data from app users

### Wikipedia REST API
**Provider**: Wikimedia Foundation  
**Purpose**: Fetch rocket descriptions and images  
**Data**: Public encyclopedia content  
**URL**: https://en.wikipedia.org/api/rest_v1/  
**Privacy**: Standard Wikimedia privacy policy applies

## 5. Permissions Required

### Notifications
- **Why**: To alert you 1 hour before launches
- **How**: Local notifications scheduled on your device
- **Control**: You can disable anytime in Settings → Space Command → Notifications

### Network
- **Why**: To fetch latest launch data
- **What's sent**: Only HTTP requests to public APIs (no personal data)

## 6. What We Don't Do

- ✅ We don't track your behavior
- ✅ We don't sell or share data
- ✅ We don't use location services
- ✅ We don't create user profiles
- ✅ We don't store password or payment info
- ✅ We don't show ads or analytics

## 7. Children's Privacy

Space Command is suitable for all ages. We comply with COPPA and GDPR requirements because we collect no personal data from anyone.

## 8. Security

All data transmission uses HTTPS encryption. However, since we don't collect personal data, the security risk is minimal.
